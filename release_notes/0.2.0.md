# React Image Demo 0.2.0

Released 2026-09-19.

This release brings the demo up to date.
It had been built with Create React App on React 17, which no longer ran on a current Node without workarounds.
It is now TypeScript on Vite, with every React dependency on its current major version, and the demo pages behave and look better for it.

## Highlights

- **TypeScript and Vite.**
  The code is strict TypeScript, and the dev server starts in well under a second.
  `npm start` still runs the app, and `npm run build` writes to `dist/`.
- **Current dependencies.**
  React 19, React Router 8, react-bootstrap 2 with Bootstrap 5.3, and react-image-crop 11.
- **Full-resolution crops.**
  The downloaded PNG holds the selected area at the source image's own resolution, rather than at its on-screen size.
- **A selection from the start.**
  Both crop pages show a centred 16:9 selection, and its preview, as soon as the image loads.
  Choosing a new file resets it.
- **Works on a phone.**
  The nav bar collapses behind a menu button, images scale to the screen, and nothing scrolls sideways.

## Fixed

- The footer was fixed to the bottom of the window and covered the end of every long page.
  It now sits below the content.
- Pages were indented twice by nested containers, and the nav bar used a Bootstrap 4 class that Bootstrap 5 ignores.
- The file picker and buttons were unstyled browser controls.
- The nav bar had an empty brand slot and did not show which page you were on.
- Unknown addresses showed a blank page; they now show a page-not-found message.

## Under the hood

- The two crop pages share one component instead of two copies of the same code.
  Navigation links are defined once for the nav bar and the footer.
- Uploaded images are held as object URLs and released when replaced or when you leave the page.
- The dev server's host and port come from `HOST` and `APP_PORT` in a local `.env`, copied from `setup/env.template`, or from the shell.
  Without them it runs on port 3000.
  `.env` is no longer committed.
- There are tests for the first time.
  Vitest covers the crop maths and routing, and Playwright runs the whole app in desktop and mobile browsers against the production build, down to checking the size of the downloaded PNG.
  `npm run check` runs lint, type checking, both test suites, and the build.
- `package-lock.json` is committed, so installs are reproducible.
- Requires Node 22.22 or later.
